# 🧊 IcebergView — застосунок для телефона

Холодний погляд на твої гроші. **Усі дані живуть лише в телефоні.**

- Токен monobank і виписка зберігаються в телефоні, зашифровані PIN-кодом (AES-256, ключ із PIN через PBKDF2, 310 000 ітерацій). PIN ніде не зберігається.
- Запити йдуть прямо з телефона в monobank — без серверів-посередників. Ця сторінка (GitHub Pages) містить лише код і даних не бачить.
- Жодних сторонніх скриптів, шрифтів чи аналітики. Політика безпеки сторінки (CSP) дозволяє звертатися лише до `api.monobank.ua` і (для скрінів, якщо ввімкнено) `api.anthropic.com`.
- Блокування після 5 хв у фоні; після 3 неправильних PIN — дедалі довші паузи.

## Встановлення на iPhone
Відкрий посилання в **Safari** → кнопка «Поділитися» → **«На початковий екран»**.

## Розділи
- **Огляд → Вільно до кінця місяця** — своїх грошей зараз + ще прийде − ще сплатити обовʼязкове; на день; світлофор; попередження про касовий розрив і несплачені платежі.
- **План** — календар платежів і доходів (крапки на днях, ✓ виконано), список дня, підсумки місяця, зобовʼязання й доходи (ручне введення), реальна ставка й переплата кожної розстрочки, прогноз на 6 місяців. Автопошук сплати у виписці monobank за словом і сумою.
- **Огляд** — що є зараз (свої гроші, борг за кредиткою, банки), рух грошей з 1-го числа: прийшло / пішло (погашення, покупки, штрафи банку), куди пішли гроші.
- **Операції** — журнал з кольорами: 🟢 прихід, 🔴 покупки, 🟣 обовʼязкові погашення, 🟠 штрафи банку, ⚪ перекази між своїми рахунками (не рахуються). Фільтри.
- **Рахунки** — картки (баланс, ліміт, борг), банки з прогресом до цілі, порожні згорнуті.
- **Налаштування** — зміна PIN, заміна токена, блокування, стерти все.

## Файли
| Файл | Що в ньому |
| --- | --- |
| `js/logic.js` | гроші, київський час, класифікація операцій (ті ж правила, що в боті) |
| `js/vault.js` | зашифроване сховище в телефоні |
| `js/plan.js` | розклад платежів, «вільно», касові розриви, прогноз, реальна ставка (та сама математика, що в боті) |
| `js/scan.js` | розпізнавання скріну через Claude API (запит прямо з телефона), перевірка відповіді |
| `js/mono.js` | запити до monobank (1 на хвилину) |
| `js/app.js` | екрани; номер версії |
| `sw.js` | кеш файлів застосунку (дані банку не кешуються) |
| `tests/` | `npm test` — тести логіки |

- 0.2.1 — «📷 Зі скріну»: розпізнавання розстрочок і кредитів через Claude API (ключ — у «Ще», зашифрований PIN); кілька записів з одного скріну, кожен перевіряєш і зберігаєш сам.
